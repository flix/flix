# LLM Policy

Flix welcomes open-source contributions — whether written by human or machine —
as long as they respect the time of the Flix core team.

1. We welcome pull requests of 50-100 lines that address minor issues in the
   compiler or standard library, such as bug fixes or small feature additions.

2. We ask that pull requests larger than 50-100 lines be discussed on GitHub or
   Zulip before they are opened.

3. We expect contributors to have read and understood all code and comments in
   their pull requests.

4. We expect contributors to take responsibility — morally, if not legally —
   for their code: to ensure it is high quality and tested, and to maintain
   it in the future.

5. We ask contributors not to open draft pull requests unless invited to do so
   — please polish the code on your own branch before opening a PR.

6. We require that any new feature, language extension, or change to the
   compiler architecture be discussed at
   https://github.com/flix/flix/discussions — with an implementation plan in
   place — before work begins.

Pull requests that do not adhere to this policy may be closed without comment
or review. It is always better to reach out to us on Zulip before
starting the work.
